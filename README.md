# کراولر قیمت — PriceCeawler

**گزارش روزانه قیمت طلا، سکه، ارز و رمزارز از [TGJU](https://www.tgju.org)**
با رابط کاربری فارسی، خروجی اکسل، و نسخه پرتابل ویندوز.

[![تست‌ها](https://github.com/mmhdih/PriceCeawler/actions/workflows/ci.yml/badge.svg)](https://github.com/mmhdih/PriceCeawler/actions/workflows/ci.yml)

## دریافت سریع

آخرین فایل `PriceCeawler-vX.Y.Z-windows-x64.exe` را از بخش
[Releases](https://github.com/mmhdih/PriceCeawler/releases/latest) دانلود و اجرا کنید.

* نیازی به نصب پایتون یا هیچ پیش‌نیاز دیگری نیست.
* رابط کاربری به‌طور خودکار در مرورگر پیش‌فرض شما باز می‌شود.
* تنظیمات، حافظه موقت و آرشیو در پوشه `PriceCeawler-Data` **کنار همان فایل exe** ساخته می‌شود؛
  بنابراین می‌توانید کل پوشه را روی فلش‌مموری ببرید.
* درستی فایل دانلودشده را می‌توانید با فایل `.sha256` کنار آن بررسی کنید.

### واحد قیمت‌ها

TGJU قیمت بازار داخلی را به **ریال** می‌دهد؛ این برنامه همه آن‌ها را به **تومان** تبدیل می‌کند.
نمادهای جهانی (انس طلا، رمزارزها، نفت) به **دلار** و بدون تبدیل نمایش داده می‌شوند.

## اجرا از روی کد

```bash
git clone https://github.com/mmhdih/PriceCeawler.git
cd PriceCeawler
pip install -r requirements.txt

python run.py                 # رابط کاربری روی http://127.0.0.1:8770
```

تنها وابستگی بیرونی `openpyxl` (برای ساخت فایل اکسل) است؛ بقیه برنامه فقط از کتابخانه استاندارد پایتون
استفاده می‌کند — تقویم شمسی، کلاینت TGJU و وب‌سرور همگی داخل همین مخزن پیاده‌سازی شده‌اند.
حداقل نسخه پایتون: **۳٫۱۱**

### خط فرمان

```bash
python run.py --port 9000 --no-browser        # اجرای سرور روی پورت دلخواه بدون باز کردن مرورگر
python run.py doctor                          # بررسی سلامت برنامه و اتصال به TGJU
python run.py crawl --symbols geram18 sekee   # کراول روزانه بدون رابط کاربری
python run.py export --symbols geram18 \
    --start 1404/01/01 --end 1404/06/31 --format xlsx --output gold.xlsx
```

با نسخه پرتابل هم دقیقاً همین دستورها کار می‌کنند:
`PriceCeawler.exe crawl --symbols geram18`

### کراول خودکار روزانه با Task Scheduler ویندوز

```powershell
schtasks /create /tn "PriceCeawler Daily" /tr "C:\Apps\PriceCeawler.exe crawl" /sc daily /st 09:00
```

## انتشار خودکار

گردش‌کار [`.github/workflows/release.yml`](.github/workflows/release.yml) با هر push روی `main`
شماره نسخه را از `priceceawler/version.py` می‌خواند:

1. اگر تگ `v{نسخه}` از قبل وجود داشته باشد، هیچ کاری انجام نمی‌شود.
2. در غیر این صورت تست‌ها اجرا، فایل `.exe` روی `windows-latest` ساخته،
   سلامت آن بررسی (`--version`، `doctor --offline`، بالا آمدن سرور و سرو شدن فونت)،
   و به‌همراه چک‌سام SHA-256 در یک Release منتشر می‌شود.

بنابراین **برای انتشار نسخه تازه فقط کافی است `__version__` را در
[`priceceawler/version.py`](priceceawler/version.py) بالا ببرید و push کنید.**

روی شاخه‌های دیگر و Pull Requestها، گردش‌کار [`ci.yml`](.github/workflows/ci.yml) تست‌ها را
روی لینوکس و ویندوز اجرا می‌کند و یک `.exe` آزمایشی به‌عنوان artifact می‌سازد (بدون انتشار Release).

## استقرار روی هاست اشتراکی (مثلاً `site.com/GoldCrawler` کنار وردپرس)

علاوه بر فایل پرتابل ویندوز، این اپ را می‌توان روی یک هاست اشتراکی معمولی هم اجرا کرد —
حتی کنار یک سایت وردپرس/المنتور موجود، بدون هیچ تداخلی — با استفاده از فایل
[`passenger_wsgi.py`](passenger_wsgi.py) که در ریشه مخزن قرار دارد.

**چرا تداخلی با وردپرس پیش نمی‌آید:** وقتی روی هاست (cPanel یا دایرکت‌ادمین) بخش
«Setup Python App» / «Python App» را برای مسیر `GoldCrawler` می‌سازید، خود پنل یک
پوشه واقعی (مثلاً `public_html/GoldCrawler`) با یک `.htaccess` اختصاصی در همان پوشه
می‌سازد. قانون rewrite وردپرس فقط وقتی صفحه را به `index.php` می‌فرستد که فایل یا
پوشه‌ای با همان مسیر واقعاً وجود نداشته باشد؛ چون `GoldCrawler` یک پوشه واقعی است،
درخواست‌های آن پیش از رسیدن به وردپرس توسط Apache/Passenger پاسخ داده می‌شوند.
المنتور فقط یک ابزار صفحه‌ساز وردپرس است و در مسیریابی سطح سرور نقشی ندارد، پس اصلاً
درگیر نمی‌شود. تنها نکته: از ساختن صفحه/نوشته‌ای با نامک `goldcrawler` در خود وردپرس
خودداری کنید تا سردرگمی پیش نیاید.

### گام‌ها (cPanel یا دایرکت‌ادمین با پشتیبانی «Python App»)

بیشتر هاست‌های اشتراکی مبتنی بر CloudLinux — چه پنل‌شان cPanel باشد چه دایرکت‌ادمین —
این قابلیت را زیر عنوانی شبیه «Setup Python App» یا «Python App» دارند (روی
Phusion Passenger ساخته شده). نام دقیق گزینه‌ها ممکن است کمی متفاوت باشد.

1. در پنل هاست، اپ پایتونی تازه بسازید:
   - **Python version**: ۳٫۱۱ یا بالاتر
   - **Application root**: پوشه‌ای که کد را در آن آپلود می‌کنید (مثلاً `goldcrawler`)
   - **Application URL**: دامنه‌تان + مسیر `GoldCrawler`
   - **Application startup file**: `passenger_wsgi.py`
   - **Application Entry point**: `application` (نام متغیر WSGI در فایل بالا)
2. کل مخزن (به‌جز `.git/`) را در همان Application root آپلود کنید.
3. پنل یک virtualenv و دستور فعال‌سازی آن را نشان می‌دهد؛ با همان venv:
   ```bash
   pip install -r requirements.txt
   ```
4. صفحه اپ در پنل را «Restart» بزنید و آدرس `https://site.com/GoldCrawler/` را باز کنید.

اگر گزینه «Python App» را در پنل پیدا نکردید، از پشتیبانی هاست بخواهید
«CloudLinux Python Selector» (یا پشتیبانی Passenger) را برای اکانت‌تان فعال کند؛
بدون آن، اجرای یک برنامه پایتونی پایدار روی هاست اشتراکی معمولی راه پشتیبانی‌شده‌ای ندارد.
جایگزین ساده‌تر (اگر مسیر زیرپوشه اهمیتی ندارد): همین اپ را روی یک **زیردامنه**
(مثلاً `goldcrawler.site.com`) مستقر کنید — همان مراحل بالا را طی می‌کنید، با این تفاوت
که هیچ نگرانی درباره مسیر یا تداخل با وردپرس وجود ندارد.

### تفاوت با فایل exe پرتابل

`passenger_wsgi.py` یک لایه ارتباطی WSGI مستقل است که همان ماژول‌های اصلی برنامه
(`crawler`, `report`, `storage`, `symbols`, …) را دوباره‌استفاده می‌کند، اما دو تفاوت
مهم با سرور تک‌کاربره‌ی فایل exe دارد که برای میزبانی روی هاست لازم بود:

- **مسیرهای نسبی**: تمام ارجاع‌های HTML/CSS/JS به‌جای مسیر مطلق (`/assets/...`) از
  مسیر نسبی استفاده می‌کنند تا زیر هر پیشوندی (`/GoldCrawler`, `/`, یا هر زیرپوشه‌ای)
  درست کار کنند.
- **توکن پایدار**: Passenger معمولاً چند پردازه (worker) موازی اجرا می‌کند؛ فایل exe
  در هر اجرا یک توکن تصادفی تازه می‌سازد (چون فقط یک پردازه دارد)، اما این کار زیر
  Passenger باعث خطای گاه‌به‌گاه «توکن نامعتبر» می‌شد چون هر worker توکن خودش را
  می‌ساخت. اینجا توکن یک‌بار ساخته و کنار داده‌های برنامه ذخیره می‌شود تا همه
  workerها به آن دسترسی داشته باشند.

### به‌روزرسانی خودکار روزانه روی هاست

زیر Passenger، برنامه فقط وقتی کد اجرا می‌کند که کسی صفحه را باز کند — یعنی «کراول
خودکار روزانه» ممکن است دیر اجرا شود اگر آن روز کسی صفحه را نبیند. برای اطمینان، یک
**Cron Job** در پنل هاست بسازید (این ویژگی همیشه بدون نیاز به SSH در دسترس است):

```bash
/home/USER/virtualenv/goldcrawler/3.11/bin/python /home/USER/goldcrawler/run.py crawl
```

(مسیر دقیق venv را همان صفحه‌ای که در گام ۳ باز کردید نشان می‌دهد.) این دستور مستقل
از رابط کاربری وب اجرا و روی همان آرشیو مشترک ذخیره می‌شود؛ زمان‌بندی روزانه (مثلاً
هر روز ساعت ۹ صبح) کافی است.

### نکته امنیتی

روی هاست عمومی، آدرس `site.com/GoldCrawler` برای هر بازدیدکننده‌ای قابل دسترسی است
(توکن داخل خود HTML صفحه فرستاده می‌شود، پس محافظتی در برابر کاربران واقعی سایت
شما ایجاد نمی‌کند — فقط جلوی خواندن مستقیم API بدون بازکردن صفحه را می‌گیرد). اگر
می‌خواهید این ابزار فقط برای خودتان باشد، ساده‌ترین راه استفاده از **Password
Protected Directories** در دایرکت‌ادمین/cPanel است: از بخش File Manager، رمز عبور
HTTP روی همان پوشه (`GoldCrawler`) بگذارید — این محافظت در سطح Apache و پیش از
رسیدن درخواست به برنامه اعمال می‌شود.

## ساختار پروژه

```
priceceawler/
├── version.py     شماره نسخه — تنها منبع حقیقت برای گردش‌کار انتشار
├── jalali.py      تقویم شمسی (پیاده‌سازی خالص پایتون، بدون وابستگی)
├── symbols.py     فهرست نمادهای TGJU و واحد قیمت هرکدام
├── tgju.py        کلاینت API با تلاش مجدد و تحلیل مقاوم پاسخ
├── crawler.py     هماهنگی دریافت موازی، حافظه موقت و آرشیو
├── report.py      ساخت سری روزانه و خروجی‌های xlsx / csv / json
├── storage.py     تنظیمات، حافظه موقت و آرشیو کنار فایل اجرایی
├── server.py      وب‌سرور محلی و API
├── fonts.py       سرو فونت Vazirmatn (بسته‌بندی‌شده، با پشتیبان CDN)
└── web/           رابط کاربری فارسی (HTML/CSS/JS بدون هیچ کتابخانه بیرونی)
```

python -m unittest discover -s tests -t . -v

## نکات امنیتی

سرور فقط روی `127.0.0.1` گوش می‌دهد، هر درخواست به `/api/` نیازمند توکن تصادفیِ همان اجراست،
هدر `Host` بررسی می‌شود (جلوگیری از DNS rebinding) و مسیرهای فایل استاتیک محدود شده‌اند.
هیچ داده‌ای جایی جز رایانه خودتان ذخیره یا ارسال نمی‌شود.
